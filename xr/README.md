# La Fabrique XR

A seated, hands-first mixed-reality control room for La Fabrique's agents,
built with the [Immersive Web SDK](https://iwsdk.dev) (WebXR).

## Run it

```bash
cd xr
npm install
npm run dev        # https://localhost:5173 with the Quest 3 emulator
npm run test:run   # unit tests
npm run build      # static site in dist/
```

Requires Node.js 20.19 or later. What is new for the Meta VR Start Developer
Competition is listed in [`CHANGELOG_COMPETITION.md`](../CHANGELOG_COMPETITION.md).
